## About the Internship

This repository contains the projects and tasks completed during my Software Development Internship at **Prodigy InfoTech**.

The internship provided an opportunity to improve my programming skills, understand practical software development concepts, and apply Python to solve real-world problems.

During this internship, I worked on five different tasks involving basic programming, conditional statements, data management, algorithms, and web scraping.

## Tasks Completed

### Task 01 – Temperature Conversion Program
A Python program that converts temperatures between different units.

**Features:**
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- User-friendly input and output

**Concepts Used:** Python, Functions, Conditional Statements, Arithmetic Operations.

### Task 02 – Number Guessing Game
A simple interactive game in which the computer generates a random number and the user tries to guess it.

**Features:**
- Random number generation
- High and low hints
- Tracks the number of attempts
- Displays the result when the correct number is guessed

**Concepts Used:** Random Module, Loops, Conditional Statements, User Input.

### Task 03 – Contact Management System
A Python-based application designed to manage contact information.

**Features:**
- Add new contacts
- View saved contacts
- Edit existing contact details
- Delete contacts
- Manage contact information

**Concepts Used:** Python, Functions, Data Structures, File Handling.

### Task 04 – Sudoku Solver
A Sudoku-solving application developed using Python and the Backtracking Algorithm.

**Features:**
- Solves Sudoku puzzles automatically
- Uses backtracking to find valid solutions
- Checks row, column, and 3×3 grid constraints
- Displays the completed Sudoku puzzle

**Concepts Used:** Python, Recursion, Backtracking Algorithm, 2D Lists.

### Task 05 – Web Scraping Product Information
A Python-based web scraping application that collects product information from an e-commerce website.

**Features:**
- Extracts book/product names
- Collects product prices
- Retrieves product ratings
- Displays information through a Tkinter GUI
- Exports collected information into a CSV file

**Concepts Used:** Python, BeautifulSoup, Requests, Tkinter, CSV, Web Scraping.

## Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Prodigy-Internship
```

**3. Install required libraries**

```bash
pip install requests beautifulsoup4
```

**4. Run the desired Python task**

Navigate to the respective task folder and execute its Python file:

```bash
python filename.py
```

Replace `filename.py` with the actual Python file name.
